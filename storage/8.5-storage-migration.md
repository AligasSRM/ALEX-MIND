# 8.5 STORAGE — Migration

## Purpose
Allow data to move between providers without changing logical vault identity.

## Migration Rules
1. Verify destination.
2. Copy and validate data.
3. Reconcile counts/metadata/versions.
4. Switch routing only after verification.
5. Preserve rollback information.

## Principle
Provider replacement must not require redesigning the vault model.
