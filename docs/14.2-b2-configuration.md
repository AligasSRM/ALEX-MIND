# Section 14.2 — B2 Configuration Contract

Status: GREEN

## Purpose
Define the runtime configuration required for the B2 provider.

## Required runtime configuration
The Worker requires:
- B2 key ID;
- B2 application key;
- B2 S3 endpoint/region;
- target bucket.

Secrets are supplied through Cloudflare Worker runtime secrets. They must never be committed to Git, embedded in source, or returned by status endpoints.

## Production bindings
The production Worker currently exposes the B2 credentials through runtime bindings and keeps the application key secret.

## Security rules
1. Never log B2 application keys.
2. Never place signed requests or credentials in D1/KV.
3. Status endpoints may report configuration presence, never credential values.
4. Provider configuration must remain replaceable.

## Failure behavior
Missing B2 credentials must fail closed. An object must not be indexed as stored when provider access cannot be established.

## Acceptance
GREEN when production configuration is present, secret material is protected, and missing configuration produces a controlled failure.
