# 3.5 SOURCES — Source Failure

## Failure Policy
A source may enter a failed or degraded state without affecting other sources.

## Required Behavior
1. Preserve the source identity.
2. Record the failure state.
3. Keep already-ingested data intact.
4. Stop unsafe ingestion when validation or authorization fails.
5. Resume only after the source boundary is healthy again.

## Security
Secrets are never written into failure records.

## Status
GREEN — defined.
