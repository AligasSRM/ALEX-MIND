# 3.4 SOURCES — Source Sync

## Primary Rule
Vault Sync is the authoritative synchronization path.

## Optional Rule
Phone Sync may be enabled independently for a source.

## Rules
- Vault Sync must be enabled before source data is considered centrally synchronized.
- Phone Sync never replaces Vault Sync.
- Sync failures are recorded; they are not silently ignored.
- No source deletion occurs as a side effect of sync failure.

## Status
GREEN — defined.
