# 3.1 SOURCES — Source Contract

## Purpose
Defines the boundary between an external source and ALEX MIND.

## Required Identity
Every source has:
- stable source ID
- source type
- source name
- active/inactive state
- sync policy reference

## Rules
- External data is untrusted until validated.
- Source identity is preserved permanently.
- Credentials never belong in source records.

## Status
GREEN — defined.
