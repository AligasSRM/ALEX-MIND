# 1.3 CORE — Source Registry

## Purpose
Defines the boundary between ALEX MIND and external sources.

## Source Record
A source has:
- stable source ID
- source type
- source name
- active/inactive state
- vault-sync policy
- optional phone-sync policy
- last synchronization state

## Initial Source Types
- Gmail
- GitHub
- Cloudflare
- Random / Unclassified

## Rules
1. Each external account is independent.
2. One source failure must not stop unrelated sources.
3. Vault synchronization is the primary persistence path.
4. Phone synchronization is optional.
5. Credentials never belong in the source registry.
