# 1.4 CORE — Routing Policy

## Purpose
Defines how ALEX MIND decides where incoming information goes.

## Routing Order
1. Validate source.
2. Accept item into Inbox.
3. Preserve raw form.
4. Classify item.
5. Resolve project references.
6. Select vault target.
7. Index the item.
8. Make it available to the relevant project workspace.

## Routing Principles
- Raw material is isolated from classified knowledge.
- Project workspaces receive relevant material; they are not the central vault.
- Phone storage is never the authoritative copy.
- Unknown or ambiguous material remains in Inbox.
- Failed validation routes to quarantine.

## No Silent Routing
ALEX MIND must not silently move information across projects or vaults without an explicit routing rule.
