# 1.5 CORE — Vault Contract

## Purpose
Defines the contract between the Core and physical storage backends.

## Vaults
### Phone Vault
Phone-originated personal material and lightweight phone-side data.

### Work Vault
Work memory, project material, architecture and operational records shared between Ali and Alex.

### Archive Vault
Long-term retained material that should remain available but is not active project workspace data.

## Contract
The Core addresses a logical vault, not a specific storage provider.

A vault backend must support:
- write
- read
- existence check
- metadata
- version-safe replacement
- failure reporting

## Provider Independence
Backends such as Backblaze B2, IDrive or future self-hosted storage are replaceable behind the vault contract.
