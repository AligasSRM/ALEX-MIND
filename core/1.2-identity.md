# 1.2 CORE — Identity

## Purpose
Defines how ALEX MIND identifies sources, items, projects and vaults.

## Identity Rules
- Every source has a stable internal identity.
- Every item keeps its source identity and source-side external ID when available.
- Every project has a stable project identity.
- Every vault has a stable vault identity.
- Internal IDs must not depend on filenames, email subjects or provider-specific paths.

## Separation
Source identity answers **where it came from**.
Project identity answers **what work it belongs to**.
Vault identity answers **where it is stored**.

These identities are related but never interchangeable.
