# 2.4 VAULTS — Storage Providers

## Purpose
Defines how physical storage providers sit behind logical vaults.

## Initial Provider Model
- Cloudflare: control/index/router layer
- Backblaze B2: storage backend
- IDrive: future interchangeable backend
- Future self-hosted storage: interchangeable backend

## Rules
- Provider credentials never enter the repository.
- A provider can be replaced without changing the logical vault model.
- Existing unrelated storage buckets remain isolated.
