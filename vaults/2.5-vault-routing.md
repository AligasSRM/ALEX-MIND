# 2.5 VAULTS — Vault Routing

## Purpose
Defines logical routing from Core to vaults.

## Routing
- Personal phone-originated data → Phone Vault
- Active work/project memory → Work Vault
- Retained inactive material → Archive Vault

## Rules
1. Core selects the logical vault.
2. Storage provider selection happens behind the vault abstraction.
3. Ambiguous routing stays in Inbox.
4. No vault may silently become another vault.
5. Workspaces consume vault data; they do not replace the vault.
